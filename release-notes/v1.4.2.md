UniFi Protect live view for Windows, one window per camera, across several consoles.

### New
- **Aspect ratio for 360° views.** Right-click a 360° camera → **360° view → Aspect ratio** to choose the window's shape: 16:9 (the default, as before), 4:3, 3:2, 1:1, 21:9, or **Any shape** to size it freely. Quad, Single view and Panorama fill whatever shape you pick. It's saved per camera and kept in layouts. In a grid window the tile sets the shape, so the option isn't offered there.

### Fix
- **Fewer security alerts.** Each time it started, Protect Panes cleared its **Start with Windows** entry in the registry, even when there was nothing to clear. Microsoft Defender can flag repeated changes to startup entries as *Anomaly detected in ASEP registry*. Now the app reads the entry first and changes it only when the setting and Windows disagree: when you turn Start with Windows on or off. Nothing else about the setting changes.

### Install or upgrade
- **From 1.4.0 or 1.4.1:** Settings → Updates → **Check for updates**, then **Install**. It's the small update, about 1.3 MB.
- **From 1.3.x:** the same, but it downloads the full installer or zip.
- **From 1.2.0 or 1.3.0 portable:** quit the app (tray → Quit) and run `ProtectPanes-Setup.exe`, or replace the folder with the zip. Your settings carry over.
- **New install:** run `ProtectPanes-Setup.exe`. It isn't code-signed, so Windows shows *Windows protected your PC*: click **More info → Run anyway**.

### Files
- `ProtectPanes-Setup.exe`: the installer.
- `ProtectPanes-win32-x64.zip`: the portable app.
- `ProtectPanes-app.asar.gz`: the small update, for copies already on this Electron version (1.4.0 and later).
- `latest.json`: the signed manifest the in-app updater reads. Its SHA-256 lines let you check the files by hand.
