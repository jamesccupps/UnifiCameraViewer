UniFi Protect live view for Windows, one window per camera, across several consoles. Project page: https://jamesccupps.github.io/UnifiCameraViewer/

Security and stability updates from Electron, and a fix for updating the portable app.

### Security
- **Electron 45.4.1** (was 45.3.1), with Chromium 156.0.8078.100 and fixes backported from Chromium, V8, ANGLE, Dawn, Skia and FFmpeg. FFmpeg is part of what plays the cameras' video.
- Node.js inside the app is on 24.22.3.

### Fixes
- **A slow memory leak on right-click is gone.** Electron kept right-clicked page elements in memory after they were removed, and every right-click on a camera opens the app's menu. That mattered most on a PC left running for weeks.
- **A full update of the portable app no longer fails because of a newer PowerShell zip module.** The step that unpacks the download used Windows PowerShell's Expand-Archive. A newer version of that module (1.2.7, which comes with PowerShell 7.6.10) doesn't work in Windows PowerShell. It gets picked up when the module was installed for Windows PowerShell, or when Protect Panes was started from a PowerShell 7 window. The update then failed and the old version stayed. The app now unpacks the zip itself. This applies to updates after this one: the update to 1.4.13 still runs your current copy's updater. If that update fails, replace the folder with the zip; your settings carry over.

### Install or upgrade
- **From 1.3.x or 1.4.x:** Settings → Updates → **Check for updates**, then **Install**. This time every copy downloads the full installer (about 120 MB) or zip (about 160 MB), not the small update, because the Electron version changed.
- **Installed with Scoop:** `scoop update protectpanes`. On a 1.4.6 copy from Scoop, use that rather than the app's **Install** button: 1.4.6 would still install this update itself, and a full update from inside the app confuses Scoop's records of it.
- **From 1.2.0 or 1.3.0 portable:** quit the app (tray → Quit) and run `ProtectPanes-Setup.exe`, or replace the folder with the zip. Your settings carry over.
- **New install:** run `ProtectPanes-Setup.exe`. It's signed by James Cupps. SmartScreen may still warn about a new download until it has seen enough of them: click **More info**, check the publisher, then **Run anyway**.

### Files
- `ProtectPanes-Setup.exe`: the installer.
- `ProtectPanes-win32-x64.zip`: the portable app (also what Scoop installs).
- `ProtectPanes-app.asar.gz`: the small update, for copies already on Electron 45.4.1. No earlier release is, so nothing uses it this time.
- `latest.json`: the signed manifest the in-app updater reads.
- `SHA256SUMS.txt`: the SHA-256 of each file above, for checking a download by hand.
