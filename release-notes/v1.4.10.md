UniFi Protect live view for Windows, one window per camera, across several consoles. Project page: https://jamesccupps.github.io/UnifiCameraViewer/

Cameras come back in front after an update, no more blank picture or "Connecting…" when a stream starts again, and livestreams now covered by the console's trusted certificate.

### Changes
- **After an update the cameras come back in front.** If camera windows were on screen when you clicked **Install and restart**, they reopen in front of other windows (without taking the focus) and the camera list starts minimized. Before, the camera list opened on top of them. If an update didn't install, the camera list opens and says so.
- **No blank picture when a stream starts again.** Changing a window's quality, restoring a minimized window, **Show cameras**, and tiles coming back after **Enlarge** keep the last picture on screen until the new stream's first frame. Before, each showed "Connecting…" and then a black picture for a moment.
- **Lock layout keeps windows from being maximized.** Win+↑, the window menu or a double-click on a grid's title bar could still maximize a locked window.

### Security
- **Livestreams now go to the address whose certificate the app trusts.** The app remembers each console's certificate the first time it connects and refuses a different one. The console hands out its livestream address on another port, with Protect's own certificate, and earlier versions connected there, so that check most likely never applied to the video streams. They now go through UniFi OS on the console's own address (unifi-protect 5.4.2, and the same for UniFi Access door readers).
- unifi-protect, the library the app talks to your consoles with, is on 5.4.2 (was 5.3.1).

### Install or upgrade
- **From 1.4.9:** Settings → Updates → **Check for updates**, then **Install**. It's a small download (a couple of MB): only the app's own file changes.
- **From 1.3.x to 1.4.8:** the same, but it downloads the full installer (about 120 MB) or zip (about 160 MB), because those copies are on an older Electron.
- **Installed with Scoop:** `scoop update protectpanes`. On a 1.4.6 copy from Scoop, use that rather than the app's **Install** button: 1.4.6 would still install this update itself, and a full update from inside the app confuses Scoop's records of it.
- **From 1.2.0 or 1.3.0 portable:** quit the app (tray → Quit) and run `ProtectPanes-Setup.exe`, or replace the folder with the zip. Your settings carry over.
- **New install:** run `ProtectPanes-Setup.exe`. It's signed by James Cupps. SmartScreen may still warn about a new download until it has seen enough of them: click **More info**, check the publisher, then **Run anyway**.

### Files
- `ProtectPanes-Setup.exe`: the installer.
- `ProtectPanes-win32-x64.zip`: the portable app (also what Scoop installs).
- `ProtectPanes-app.asar.gz`: the small update, for copies already on Electron 45.3.1 (1.4.9).
- `latest.json`: the signed manifest the in-app updater reads.
- `SHA256SUMS.txt`: the SHA-256 of each file above, for checking a download by hand.
