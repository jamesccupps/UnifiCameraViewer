UniFi Protect live view for Windows, one window per camera, across several consoles. Project page: https://jamesccupps.github.io/UnifiCameraViewer/

Double-click any camera to enlarge it, and again to put it back.

### Changes
- **Double-click a camera window to make it fill its screen.** Double-click again and it goes back exactly where it was. It works with **Lock layout** on, and the enlarged size is never saved as the window's place. Grid tiles work as before: double-click fills the grid window with that tile.
- **360° quad views:** double-click a view and the window fills the screen with just that view. Double-click again for the four views, with the window back in its place. Dragging a view still aims it.
- **Lock layout** still locks where the 360° views point (drag and scroll), but no longer blocks double-clicking a view to look closer.

### Install or upgrade
- **From 1.4.9 or 1.4.10:** Settings → Updates → **Check for updates**, then **Install**. It's a small download (a couple of MB): only the app's own file changes.
- **From 1.3.x to 1.4.8:** the same, but it downloads the full installer (about 120 MB) or zip (about 160 MB), because those copies are on an older Electron.
- **Installed with Scoop:** `scoop update protectpanes`. On a 1.4.6 copy from Scoop, use that rather than the app's **Install** button: 1.4.6 would still install this update itself, and a full update from inside the app confuses Scoop's records of it.
- **From 1.2.0 or 1.3.0 portable:** quit the app (tray → Quit) and run `ProtectPanes-Setup.exe`, or replace the folder with the zip. Your settings carry over.
- **New install:** run `ProtectPanes-Setup.exe`. It's signed by James Cupps. SmartScreen may still warn about a new download until it has seen enough of them: click **More info**, check the publisher, then **Run anyway**.

### Files
- `ProtectPanes-Setup.exe`: the installer.
- `ProtectPanes-win32-x64.zip`: the portable app (also what Scoop installs).
- `ProtectPanes-app.asar.gz`: the small update, for copies already on Electron 45.3.1 (1.4.9 and 1.4.10).
- `latest.json`: the signed manifest the in-app updater reads.
- `SHA256SUMS.txt`: the SHA-256 of each file above, for checking a download by hand.
