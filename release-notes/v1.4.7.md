UniFi Protect live view for Windows, one window per camera, across several consoles. Project page: https://jamesccupps.github.io/UnifiCameraViewer/

Grid tiles change cameras and quality without going blank, and copies installed with Scoop now update through Scoop.

### New
- **Install with Scoop.** If you use [Scoop](https://scoop.sh):
  ```
  scoop bucket add jamesccupps https://github.com/jamesccupps/scoop-bucket
  scoop install jamesccupps/protectpanes
  ```

### Changes
- **No blank tile when a grid tile changes.** A tile that cycles through cameras, a tile you enlarge, and a tile whose quality you pick from its menu now keep the old picture until the new one is up. Before, each of these went black with *Connecting…* for a second or two while the new stream started. For that second or two the tile pulls both streams. Separate camera windows still restart in place when their quality changes.
- **Copies installed with Scoop leave updating to Scoop.** They still tell you when there's a new version, with the command to run (`scoop update protectpanes`), but they don't download it. An update installed from inside the app could leave Scoop's own records of the app confused.

### Install or upgrade
- **From 1.4.5 or 1.4.6:** Settings → Updates → **Check for updates**, then **Install**. It's the small update, about 1.4 MB.
- **From 1.3.x or 1.4.0 to 1.4.4:** the same, but it downloads the full installer (about 120 MB) or zip (about 160 MB), since 1.4.5 moved to a new Electron.
- **Installed with Scoop:** `scoop update protectpanes`. A 1.4.6 copy from Scoop can also take this update from inside the app; after that, updates go through Scoop.
- **From 1.2.0 or 1.3.0 portable:** quit the app (tray → Quit) and run `ProtectPanes-Setup.exe`, or replace the folder with the zip. Your settings carry over.
- **New install:** run `ProtectPanes-Setup.exe`. It isn't code-signed, so Windows shows *Windows protected your PC*: click **More info → Run anyway**.

### Files
- `ProtectPanes-Setup.exe`: the installer.
- `ProtectPanes-win32-x64.zip`: the portable app (also what Scoop installs).
- `ProtectPanes-app.asar.gz`: the small update, for copies already on Electron 45.2.3 (1.4.5 and later).
- `latest.json`: the signed manifest the in-app updater reads. Its SHA-256 lines let you check the files by hand.
