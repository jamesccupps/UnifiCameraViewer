UniFi Protect live view for Windows, one window per camera, across several consoles. Project page: https://jamesccupps.github.io/UnifiCameraViewer/

Security updates from Electron. Nothing else in the app changes.

### Security
- **Electron 45.3.1** (was 45.2.3), with Chromium 156.0.8078.96 and fixes backported from Chromium, Dawn and V8.
- Chromium no longer trusts certificates from eMudhra's revoked RSA intermediate authorities.
- Electron also fixes hidden windows that some PCs drew as a blank box, seen with overlay tools such as ASUS Smart Input installed.

### Install or upgrade
- **From 1.3.x or 1.4.x:** Settings → Updates → **Check for updates**, then **Install**. This time every copy downloads the full installer (about 120 MB) or zip (about 160 MB), not the small update, because the Electron version changed.
- **Installed with Scoop:** `scoop update protectpanes`. On a 1.4.6 copy from Scoop, use that rather than the app's **Install** button: 1.4.6 would still install this update itself, and a full update from inside the app confuses Scoop's records of it.
- **From 1.2.0 or 1.3.0 portable:** quit the app (tray → Quit) and run `ProtectPanes-Setup.exe`, or replace the folder with the zip. Your settings carry over.
- **New install:** run `ProtectPanes-Setup.exe`. It's signed by James Cupps. SmartScreen may still warn about a new download until it has seen enough of them: click **More info**, check the publisher, then **Run anyway**.

### Files
- `ProtectPanes-Setup.exe`: the installer.
- `ProtectPanes-win32-x64.zip`: the portable app (also what Scoop installs).
- `ProtectPanes-app.asar.gz`: the small update, for copies already on Electron 45.3.1. No earlier release is, so nothing uses it this time.
- `latest.json`: the signed manifest the in-app updater reads.
- `SHA256SUMS.txt`: the SHA-256 of each file above, for checking a download by hand.
