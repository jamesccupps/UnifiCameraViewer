UniFi Protect live view for Windows, one window per camera, across several consoles. Project page: https://jamesccupps.github.io/UnifiCameraViewer/

The app is now code-signed. Nothing else changes.

### Changes
- **Signed by James Cupps.** `ProtectPanes.exe`, its uninstaller and `ProtectPanes-Setup.exe` carry an Authenticode signature (Azure Artifact Signing, the certificate Slate, NoteForge, PingerPlot and UniFi Stock Watcher are signed with), so Windows names the publisher instead of *Unknown publisher*. SmartScreen may still warn about a new download until it has seen enough of them. In-app updates are still checked against the app's own Ed25519 signature first, as before.

### Install or upgrade
- **From 1.3.x or 1.4.x:** Settings → Updates → **Check for updates**, then **Install**. This one downloads the full installer (about 120 MB) or zip (about 160 MB) rather than the small update, so the signed program replaces the old one.
- **Installed with Scoop:** `scoop update protectpanes`. On a 1.4.6 copy from Scoop, use that rather than the app's **Install** button: 1.4.6 would still install this update itself, and a full update from inside the app confuses Scoop's records of it.
- **From 1.2.0 or 1.3.0 portable:** quit the app (tray → Quit) and run `ProtectPanes-Setup.exe`, or replace the folder with the zip. Your settings carry over.
- **New install:** run `ProtectPanes-Setup.exe`.

### Files
- `ProtectPanes-Setup.exe`: the installer.
- `ProtectPanes-win32-x64.zip`: the portable app (also what Scoop installs).
- `latest.json`: the signed manifest the in-app updater reads. Its SHA-256 lines let you check the files by hand.

No `ProtectPanes-app.asar.gz` this time: every copy takes the full update.
