UniFi Protect live view for Windows, one window per camera, across several consoles.

### New in 1.3.0
- **Installer.** `ProtectPanes-Setup.exe` installs for your Windows user, with no admin prompt. It adds Start menu and desktop shortcuts and an uninstaller in **Settings → Apps**. The zip is still here for portable use.
- **Layout editor** (Layouts → **New layout…**). Pick a screen and a grid (2×2, 1+5, 1+7, 3×3, 2+8, 1+12, 4×4, 5×5…), then drag cameras onto the tiles, or start from what's already on screen. Each 360° camera can show as Quad (the default), Single view, Panorama or Fisheye in its tile. Save it, or save and apply it.
- **Arrange.** One click tiles the camera windows on a screen: either the best-fitting grid for that screen's resolution and shape (16:9, ultrawide, portrait), or one of the fixed layouts. The top-left camera gets the big tile. Optionally each camera's stream quality follows its tile size, so a wall of small tiles doesn't decode 4K.
- **Close all** per console, next to Show all.
- **A cleaner camera list.** It has Cameras / Layouts / Settings tabs, a camera search, and hover tips on every control. Edit, Reconnect and Remove are in a "⋯" menu. An About section has the project page and log folder.
- **Single view** for 360° cameras (right-click → 360° view).

### Fixes
- **Security:** the HTTPS/WebSocket client that talks to your consoles (undici) was on a version with several high-severity advisories, including a certificate-validation bypass. It's now on the patched 8.12.3.
- Updates now work for both installed and portable copies. Installed copies run the new installer silently, so the uninstaller and shortcuts stay intact.

### Install or upgrade
- **New install:** run `ProtectPanes-Setup.exe`. It isn't code-signed, so Windows shows *Windows protected your PC*: click **More info → Run anyway**.
- **From 1.2.0:** Settings → Updates → **Check for updates**, then **Install**. A 1.2.0 copy updates from the zip and stays portable. To switch to the installer, run `ProtectPanes-Setup.exe` once; your settings carry over.
- **From 1.0 or 1.1:** quit the app (tray → Quit) and run the installer, or replace the folder with the zip.

### Files
- `ProtectPanes-Setup.exe`: the installer.
- `ProtectPanes-win32-x64.zip`: the portable app.
- `latest.json`: the signed manifest the in-app updater reads. Its SHA-256 lines let you check the two files by hand.
