UniFi Protect live view for Windows, one window per camera, across several consoles. Project page: https://jamesccupps.github.io/UnifiCameraViewer/

The rest of the fixes from a second review, each checked by a test that failed before it.

### Fixes
- **360° views keep their aim when the settings refresh during a drag.** A refresh (a console reconnecting, a Settings change, a lens change in another copy of the camera) used to snap the view back in the middle of a drag, and right after one it could throw the whole move away. The aim is now also saved the moment you let go.
- **Update checks happen once a day**, not only when the app starts, so a PC that runs for weeks still hears about a release. It only tells you; nothing is downloaded until you click.
- **Saved layouts forget the cameras of a console you removed.** Applying a layout already skipped them, but the Layouts tab still counted them and exports still carried them.
- **A switch in the camera list goes back** when its change didn't take, even if the list happened to be refreshing at that moment.
- Every camera the list asks main for is now checked the same way. Only the list's own page can send these requests, so this tidies things up rather than closing a hole.

### Install or upgrade
- **From 1.4.5:** Settings → Updates → **Check for updates**, then **Install**. It's the small update, about 1.4 MB.
- **From 1.3.x or 1.4.0 to 1.4.4:** the same, but it downloads the full installer (about 120 MB) or zip (about 160 MB), since 1.4.5 moved to a new Electron.
- **From 1.2.0 or 1.3.0 portable:** quit the app (tray → Quit) and run `ProtectPanes-Setup.exe`, or replace the folder with the zip. Your settings carry over.
- **New install:** run `ProtectPanes-Setup.exe`. It isn't code-signed, so Windows shows *Windows protected your PC*: click **More info → Run anyway**.

### Files
- `ProtectPanes-Setup.exe`: the installer.
- `ProtectPanes-win32-x64.zip`: the portable app.
- `ProtectPanes-app.asar.gz`: the small update, for copies already on Electron 45.2.3 (1.4.5 and later).
- `latest.json`: the signed manifest the in-app updater reads. Its SHA-256 lines let you check the files by hand.
