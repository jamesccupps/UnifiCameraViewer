UniFi Protect live view for Windows, one window per camera, across several consoles. Project page: https://jamesccupps.github.io/UnifiCameraViewer/

Fixes from a full review of the app, each checked by a test that failed before it.

### Security
- **Importing settings no longer changes where updates come from.** The update location now stays as each PC has it, like Start with Windows. A settings file could otherwise point update checks at a network share. The app would open that share at every start, and Windows sends a share the user's network credentials. The signature check stopped fake updates, but not that.
- Imported settings are checked: only settings this version knows, each with the right kind of value. Anything else takes its default.
- Releases are now signed in a separate step that never runs the build's third-party tools, so none of them can read the signing key.

### Fixes
- A minimized or hidden window of a UniFi Access door reader now stays paused. Video it had already queued used to reach the window, and the camera list showed it as live.
- Settings keep saving if `config.json` is deleted while the app runs (by a sync tool or antivirus, say). Before, every save failed until a restart.
- Import cleans up console addresses written as web addresses (`https://10.0.0.5/` becomes `10.0.0.5`), the way Add console does. A file that has the same console twice brings it in once.
- Import reads a settings file saved with a byte-order mark, as Windows PowerShell 5.1 saves UTF-8.
- A 360° view whose saved settings miss some values (a hand-edited file) gets them filled in, instead of staying blank.
- A camera whose stream keeps ending waits a few seconds before reconnecting, and says so, instead of reconnecting over and over.
- The camera list says *in grid* only for the camera a cycling tile is showing, not for the other cameras in its cycle.

### Install or upgrade
- **From 1.4.0, 1.4.1, 1.4.2 or 1.4.3:** Settings → Updates → **Check for updates**, then **Install**. It's the small update.
- **From 1.3.x:** the same, but it downloads the full installer or zip.
- **From 1.2.0 or 1.3.0 portable:** quit the app (tray → Quit) and run `ProtectPanes-Setup.exe`, or replace the folder with the zip. Your settings carry over.
- **New install:** run `ProtectPanes-Setup.exe`. It isn't code-signed, so Windows shows *Windows protected your PC*: click **More info → Run anyway**.

### Files
- `ProtectPanes-Setup.exe`: the installer.
- `ProtectPanes-win32-x64.zip`: the portable app.
- `ProtectPanes-app.asar.gz`: the small update, for copies already on this Electron version (1.4.0 and later).
- `latest.json`: the signed manifest the in-app updater reads. Its SHA-256 lines let you check the files by hand.
