UniFi Protect live view for Windows, one window per camera, across several consoles. Project page: https://jamesccupps.github.io/UnifiCameraViewer/

Security updates, and a question before a grid loses cameras.

### Security
- **Electron 45.2.3** (was 45.0.0), with newer Chromium and 120 fixes backported from Chromium, V8, ffmpeg and the GPU stack. Some are in the parts that play the cameras' video: Chromium's MediaSource buffer handling, and ffmpeg's H.264 and MP4 parsing.
- **The app's exe is locked down** with Electron's fuses. It no longer works as a general-purpose Node.js (`ELECTRON_RUN_AS_NODE`), ignores `NODE_OPTIONS`, refuses a debugger (`--inspect`), and loads only its own `app.asar`.
- **Installing an update starts Windows' own PowerShell, by its full path.** The update helper used to ask for `powershell.exe` by name from the updates folder, and Windows looks in that folder first, so a `powershell.exe` left there would have run instead. Only your Windows account can write to that folder, so this closes a gap for something already running as you, not a way in.
- undici, the HTTPS client the app talks to your consoles with, is on 8.12.4. The six advisories it fixes are in parts this app doesn't use; it's kept current so the app never ships a version with open advisories.

### Fixes
- **Switching a grid to a smaller layout asks first.** Grid → Layout takes out the cameras that don't fit, with their tile settings, and saves straight away. Switching a 3 × 3 grid to 2 × 2 used to remove five cameras without a word. Now it names them and asks. A bigger layout doesn't ask.

### Install or upgrade
- **From 1.3.x or 1.4.x:** Settings → Updates → **Check for updates**, then **Install**. This time every copy downloads the full installer (about 120 MB) or zip (about 160 MB), not the small update, because the Electron version changed. Small updates come back with the next release.
- **From 1.2.0 or 1.3.0 portable:** quit the app (tray → Quit) and run `ProtectPanes-Setup.exe`, or replace the folder with the zip. Your settings carry over.
- **New install:** run `ProtectPanes-Setup.exe`. It isn't code-signed, so Windows shows *Windows protected your PC*: click **More info → Run anyway**.

### Files
- `ProtectPanes-Setup.exe`: the installer.
- `ProtectPanes-win32-x64.zip`: the portable app.
- `ProtectPanes-app.asar.gz`: the small update, for copies already on Electron 45.2.3. No earlier release is, so nothing uses it this time.
- `latest.json`: the signed manifest the in-app updater reads. Its SHA-256 lines let you check the files by hand.
