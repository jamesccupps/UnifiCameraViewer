UniFi Protect live view for Windows, one window per camera, across several consoles.

### New in 1.4.0
- **Grid windows.** In the layout editor (Layouts → **New layout…**), set **Open as → One grid window** to put all the cameras in the tiles of one window, like a Protect liveview. Move it, resize it, maximize it or put it in full screen.
  - Each tile keeps everything a camera window has: 360° views you can aim, the clock, the right-click menu.
  - Each tile picks its stream quality from its size.
  - Right-click a tile to change its camera's settings in this grid, switch the grid's **Layout**, **Edit grid…** or **Close grid**. Right-click an empty tile to **Put a camera here**.
  - Grid windows reopen where they were and hide with **Hide cameras**.
- **Hide from list.** **Hide** on a camera's row tucks a camera nobody uses (an offline one, say) into **Hidden from list** at the bottom of its console. **Show all** and the layout editor skip it. **Show in list** brings it back.
- **Camera previews.** Each camera in the list shows a still from the camera, refreshed about once a minute while the list is open. Hover one for a bigger view, also in the layout editor. Offline cameras say so. Turn previews off in **Settings → Show camera previews**.
- **Adjust picture.** Right-click a camera → **Adjust picture…** for Brightness and Contrast sliders. **Apply to all cameras** can copy them too.
- **Smaller updates.** From now on, a release that keeps the same Electron version is a ~1.5 MB download instead of 120-160 MB, still signed and checked before it's installed. Installed copies' Settings → Apps entry keeps showing the last full installer's version until the next full update.

### Fixes
- Saved console passwords now use Electron's current encryption API. The old one is deprecated and would have stopped reading them on a later Electron upgrade. Existing passwords keep working, and going back to an older version still reads them.

### Install or upgrade
- **From 1.3.0 (installed) or 1.3.1:** Settings → Updates → **Check for updates**, then **Install**. This one still downloads the full installer or zip, since 1.3.x doesn't know about small updates. From 1.4.0 on they're small.
- **From 1.2.0 or 1.3.0 portable:** those can't update themselves. Quit the app (tray → Quit) and run `ProtectPanes-Setup.exe`, or replace the folder with the zip. Your settings carry over.
- **New install:** run `ProtectPanes-Setup.exe`. It isn't code-signed, so Windows shows *Windows protected your PC*: click **More info → Run anyway**.

### Files
- `ProtectPanes-Setup.exe`: the installer.
- `ProtectPanes-win32-x64.zip`: the portable app.
- `ProtectPanes-app.asar.gz`: the small update, for copies already on this Electron version.
- `latest.json`: the signed manifest the in-app updater reads. Its SHA-256 lines let you check the files by hand.
