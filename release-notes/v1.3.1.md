UniFi Protect live view for Windows, one window per camera, across several consoles.

### Fixes
- **In-app updates of the portable (zip) copy failed** when the app had been started from Explorer or a shortcut, which is almost always. The update downloaded and verified, then the log said *couldn't move … aside (a file in it is still in use)*, and the old version restarted. The update helper was starting inside the app's folder, and Windows won't rename a folder some process is working in. That includes the helper itself. The helper now starts from the updates folder.
- **Arrange and the layout editor's Use what's on screen could miss windows.** A camera window that had just opened, been restored, or been moved to another screen sometimes wasn't counted until something else changed in the camera list.

### Install or upgrade
- **New install, or switching from the portable copy:** quit the app (tray → Quit) and run `ProtectPanes-Setup.exe`. It installs for your Windows user, with no admin prompt, and adds Start menu and desktop shortcuts. Your cameras, layouts and settings carry over. It isn't code-signed, so Windows shows *Windows protected your PC*: click **More info → Run anyway**.
- **From 1.2.0 or 1.3.0 (portable):** those versions have the bug, so they can't update themselves. Install once by hand: either run the installer as above, or quit the app and replace the folder with the zip. From 1.3.1 on, Settings → Updates → **Install** works.
- **From 1.3.0 (installed with Setup.exe):** Settings → Updates → **Check for updates**, then **Install**. Installed copies don't rename their folder, so this bug didn't affect them.

### Files
- `ProtectPanes-Setup.exe`: the installer.
- `ProtectPanes-win32-x64.zip`: the portable app.
- `latest.json`: the signed manifest the in-app updater reads. Its SHA-256 lines let you check the two files by hand.
