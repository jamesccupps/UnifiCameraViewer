UniFi Protect live view for Windows, one window per camera, across several consoles. Project page: https://jamesccupps.github.io/UnifiCameraViewer/

Fixes from an outside review of the code.

### Fixes
- **Apply to all → All of the above no longer turns the clock on everywhere.** Used from a 360° window that you hadn't changed, it put the app's time on every normal camera, over the camera's own timestamp. It now copies only a time setting you chose, and leaves each camera on its own default otherwise. **Show time: on** or **off** on its own still does what it says.
- **No more two layouts with the same name.** Saving a layout from the layout editor under another layout's name left both. Now it replaces the other one, as saving under an existing name already did everywhere else.
- **A hand-edited or damaged settings file can't hand the app a setting of the wrong type.** Each setting falls back to its default instead, and a console whose address isn't text is left out. Both are noted in the log.

### Security
- `SECURITY.md` now lists a known limit: video from cameras on UniFi Access door readers isn't checked against the console's remembered certificate. Those streams come from Protect's own listener on another port, and checking them is on the roadmap. Logins and every other camera's video are checked.

### Install or upgrade
- **From 1.4.9, 1.4.10 or 1.4.11:** Settings → Updates → **Check for updates**, then **Install**. It's a small download (a couple of MB): only the app's own file changes.
- **From 1.3.x to 1.4.8:** the same, but it downloads the full installer (about 120 MB) or zip (about 160 MB), because those copies are on an older Electron.
- **Installed with Scoop:** `scoop update protectpanes`. On a 1.4.6 copy from Scoop, use that rather than the app's **Install** button: 1.4.6 would still install this update itself, and a full update from inside the app confuses Scoop's records of it.
- **From 1.2.0 or 1.3.0 portable:** quit the app (tray → Quit) and run `ProtectPanes-Setup.exe`, or replace the folder with the zip. Your settings carry over.
- **New install:** run `ProtectPanes-Setup.exe`. It's signed by James Cupps. SmartScreen may still warn about a new download until it has seen enough of them: click **More info**, check the publisher, then **Run anyway**.

### Files
- `ProtectPanes-Setup.exe`: the installer.
- `ProtectPanes-win32-x64.zip`: the portable app (also what Scoop installs).
- `ProtectPanes-app.asar.gz`: the small update, for copies already on Electron 45.3.1 (1.4.9 to 1.4.11).
- `latest.json`: the signed manifest the in-app updater reads.
- `SHA256SUMS.txt`: the SHA-256 of each file above, for checking a download by hand.
